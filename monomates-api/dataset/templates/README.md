# Future pilot data templates

These CSV files are empty schemas for later real-world data collection. They are not loaded automatically by the application.

- `pilot-sensor-events.csv`: device measurements and later validation labels.
- `pilot-bin-inventory.csv`: deployed-bin and device registry export.
- `pilot-vouchers.csv`: reward catalogue import template.
- `pilot-data-dictionary.csv`: field definitions and expected types.

Keep synthetic records and pilot records in separate databases or clearly marked environments. Never present the synthetic dataset as measured project performance.
